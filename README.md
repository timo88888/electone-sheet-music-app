# エレクトーン楽譜生成アプリ（v8）

マウス操作で音符を配置していく、エレクトーン用の3段譜表（上鍵盤・下鍵盤・ペダル）対応の楽譜エディタです。Electron製のデスクトップアプリで、ローカル環境で完結します。

## 起動方法

```bash
npm install
npm start
```

## キーボードショートカット

| | |
|---|---|
| Ctrl+S / Ctrl+Shift+S | 上書き保存 / 名前を付けて保存 |
| Ctrl+O | 開く |
| Ctrl+P | 印刷 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+C / Ctrl+X / Ctrl+V | コピー / 切り取り / 貼り付け |
| ↑ / ↓ | 選択中の音符を1つ上下に動かす |
| Delete / Backspace | 選択中の音符を削除 |
| Esc | 選択やスラー等の入力待ちを解除 |

## 画面構成

- 最上部の**クイックアクセスバー**: タイトル、元に戻す/やり直す/削除、小節数、BPM、再生、ズームなど常に使う操作
- その下の**タブ+リボン**（ホーム/小節/記号/編集/出力）: Officeソフトのように、タブを切り替えて関連する操作をまとめて表示
- 譜面をクリックすると**フローティングツールボックス**（音符・休符・臨時記号の選択パネル）が画面上に表示されます。ドラッグで好きな位置に移動でき、閉じるまで表示され続けるので、次々と音符を置きながら種類を変更できます

## 使い方（ホームタブ）

- 音符の種類（全音符〜16分音符・付点・三連符）、休符の種類（全休符〜16分休符）、臨時記号（♯/♭/♮）を選び、**譜表を1回クリックするとその場に配置されます**。置いた音符はそのまま選択状態（青）になり、次の音符を置くと選択がそちらへ移ります。
- **1小節に入る量は拍子で決まっています。** 入りきらない音符を置こうとすると「◯小節目にはこれ以上音符を入れられません」と表示され、何も配置されません（後ろの小節に押し出されることはありません）。
- 小節を途中まで書いた状態で次の小節に音符を置くと、**前の小節の残りが自動で休符で埋まります**。
- 三連符は「3」ボタンを押した状態で3個続けて音符を置くと、自動でグループ化されて連桁とかっこ「3」が付きます。
- 配置済みの音符をクリックして選択するとドラッグで音高を変更、削除ボタンかBackspace/Deleteキーで削除できます。選択すると「記号」タブの各ボタンにその音符の現在の装飾（タイ・スラー・強弱・アーティキュレーション）が反映され、そこから編集・解除できます。

## 使い方（小節タブ）

- 拍子記号（例: `4/4` `3/4` `6/8`）、弱起（ピックアップ小節）の拍数、上鍵盤/下鍵盤/ペダルそれぞれの音部記号（ト音記号/ヘ音記号）を変更できます。新規作成時のデフォルトは下鍵盤・ペダルがヘ音記号です。
- 「対象小節」の番号を指定して、小節線（通常線/二重線/終止線）、リピート開始・終了、n番括弧（1番/2番…）、マーカー（Segno/D.C./D.S./Fine/Coda）、レジストレーション・コードのテキストを設定します。レジストレーション/コードは譜表上の該当箇所をクリックしても編集できます。
- **n番括弧は1つの小節に対して設定します**（1つの括弧＝1小節）。右端を閉じない鉤括弧の形で表示されます。2小節にまたがる終止を書きたい場合は、その先頭の小節に括弧を付けてください。
- 各小節の上部には作業用の小節番号（印刷/PDF出力時は非表示）が薄く表示されます。クリックするとその小節が選択され、右クリックすると小節線・リピート・マーカー・レジストレーション/コードをまとめて編集できるメニューが出ます。

## 使い方（記号タブ）

- 音符を選択した状態で、タイ・スラー・グリッサンド・**8va/8vb（オクターブ記号）**・強弱(pp〜ff)・クレッシェンド/デクレッシェンド・アーティキュレーション（スタッカート/テヌート/アクセント/マルカート/フェルマータ/トリル/ターン/モルデント/アルペジオ）・歌詞を付けられます。強弱記号などは標準的な配置（譜表の下）に表示されます。
- **8va/8vb** は、開始する音符を選んでボタンを押し、続けて範囲の終わりにしたい音符をクリックします。囲まれた音符は書かれた位置より1オクターブ上（下）で鳴ります。
- 音符を右クリックすると、**符尾の向き**（自動/上向き/下向き）と**ここで連桁を分ける**が選べます。自動の判断が読みにくいときの手動調整用です。

## 使い方（編集タブ）

- **移調**: 開始/終了の小節番号と度数を指定して音階度数単位で移調します。

## 範囲選択とコピー・ペースト（右クリック）

- 譜面の空いている場所をクリックしたままドラッグすると、1つのパートの小節範囲を選択できます（青くハイライト表示）。譜面や余白をクリックすると選択は解除されます。
- 選択した状態で**右クリック**すると、コピー・ペースト・まとめて削除・タイ・スラー・グリッサンド・連符・連符の解除ができるメニューが出ます（Excel/Wordのような操作感）。リボンには置かず、選択したその場で出るメニューに集約しています。
- ペースト先の小節が足りない場合は自動で追加されます。貼り付ける内容が小節に入りきらない場合はペーストされません。

## 使い方（出力タブ）

- **保存**（Ctrl+S）は、いま開いているファイルに上書き保存します。まだ一度も保存していない場合は保存先を聞きます。**名前を付けて保存**（Ctrl+Shift+S）は毎回保存先を選べます。**開く**（Ctrl+O）で読み込み。
- ウィンドウのタイトルに現在のファイル名が出ます。未保存の変更があるときは先頭に「●」が付きます。
- 保存していない変更があるときに「開く」やテンプレートからの新規作成を行うと、破棄してよいか確認します。
- 「印刷」「PDF書き出し」はどちらも**楽譜だけ**を出力します。タブ・リボン・小節番号・選択中のハイライトは印刷されません。用紙はA4（縦）で、譜面1ページが用紙1枚に収まり、末尾に白紙のページは付きません。
- 「MIDI書き出し」「WAV書き出し」で音声・MIDIファイルを書き出せます（保存先を選べます。MP3は未対応）。MIDIには各段の音色（プログラムチェンジ）・拍子・調号・強弱に応じたベロシティが入ります。
- 「テンプレート」で拍子・小節数・弱起設定・音部記号だけの空フォーマットを保存/新規作成できます。

## 再生に反映されるもの

- 強弱記号（pp〜ff）は次の指示が出るまで有効です。アクセント/マルカートは強く、スタッカート/スタッカーティッシモは短く鳴ります（後続の音符の位置はずれません）。
- リピート、n番括弧（1番/2番…）、D.C./D.S./Segno/Fine/Coda を演奏順に展開します。Codaは「飛ぶ側の小節」と「コーダ本体の先頭小節」の2か所に設定してください（1か所だけだと飛び先がないため無視されます）。
- グリッサンドは、開始音から終了音まで**白鍵を順に滑らせる**音で鳴ります（鍵盤楽器で実際に手を滑らせたときの音）。書かれた開始音符の長さの中に収まるので、後ろの音符の位置はずれません。
- 8va/8vb で囲まれた音符は、書かれた位置より1オクターブ上（下）で鳴ります。
- 段ごとに選んだ音色は、画面上の再生・WAV書き出し・MIDI書き出しすべてに反映されます。

## 開発

```bash
npm test
```

譜面モデル・演奏順の展開・音符間リンク（タイ/スラー/グリッサンド）の整合性・再生イベント・MIDI書き出しについて、DOMを使わない単体テストが入っています。

## 楽譜の1ページ目

- 中央上部にタイトル、左に作詞、右に作曲を入力できるテキスト欄があります（クリックして直接入力、Enterや他の場所をクリックで確定）。タイトルはクイックアクセスバーの「タイトル」欄とも連動します。
- 新規作成時は最初のページ1枚分（16小節）があらかじめ用意されています。小節の右クリックメニューから「終止線」を設定すると、それ以降の小節は自動的に削除されます。

## 既知の制限

- 拍子は各譜面で1種類固定です（曲の途中での拍子変更は未対応。譜面全体をまとめて変更する形です）。拍子を変えたときに拍数が入りきらない小節があれば、音符を小節をまたいで詰め直すかどうか確認します。
- 繰り返し記号は「D.C./D.S.が発生した後は内側のリピートを取らない」という簡略化されたロジックです。複雑なネスト構成では実際の演奏順と異なる場合があります。D.C./D.S.のあとは、n番括弧は最後の番号（2番括弧まであれば2番）を通ります。
- MP3書き出しは未対応（MIDI・WAVは対応）。
- 音部記号はト音記号・ヘ音記号のみ選択可能です（ハ音記号などは非対応）。
- 移調は音階度数単位です（半音単位ではなく、臨時記号を自動生成する形の移調ではありません）。
- 範囲選択は1つのパート・1つの譜面内でのみ有効です（複数パート同時選択や、コピー内容をファイルとして保存することは未対応）。
- 三連符は「3個で2拍分」の標準的な三連符のみ対応です（五連符・七連符も同じ考え方で、変則的な比率は未対応）。連符は音符を右クリックして「連符を解除」で戻せます。
